# Why a Band You Can Check Matters

The economy has no ending. It runs for decades of simulated time, and "it looks about right" is not a result anyone can act on. A band is how the town says what healthy means: rents that a median household can carry, wealth not collapsing into a single owner, houses neither all empty nor all overflowing, nobody homeless at the reference scale.

The bands already exist and are already asserted, which is the important part — nobody has to remember them. What tends to fail is not the checking, it is the record around it. A band broke, was understood, was written down in a comment, and was later fixed by someone else. The comment stayed. Months on, the code still tells a reader to expect a failure that never arrives, and the next real failure gets read as "that old known issue" instead of a new break.

So this track does three unglamorous things: it gives every band a number so it can be checked at all, it makes a failure say which report produced it so nobody has to bisect to find out, and it removes the tolerated reds and the "still opt-in" markers that make the economy's state ambiguous.

None of this changes what a player experiences. It changes whether the next person can tell whether the town is broken.
